# CV fonts

Embedded in the CV builder's preview and generated PDFs (`src/features/cv`).
All four families cover Latin and Cyrillic and are licensed under the
SIL Open Font License 1.1 (see the `*-OFL.txt` files):

| Option | Family | Word export uses |
| --- | --- | --- |
| Garamond | EB Garamond | Garamond |
| Times | Tinos (metric-compatible with Times New Roman) | Times New Roman |
| Helvetica | Arimo (metric-compatible with Arial) | Arial |
| Courier | Cousine (metric-compatible with Courier New) | Courier New |

Downloaded from Google Fonts. Each has regular, bold and italic.
